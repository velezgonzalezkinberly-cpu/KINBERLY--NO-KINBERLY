Reconocimiento de imágenes con inteligencia artificial

Aplicación web progresiva desarrollada en el CBTIS 260. Utiliza un modelo entrenado en Google Teachable Machine para clasificar fotografías directamente en el navegador y mostrar qué tan seguro está el modelo de cada resultado.

¿Qué es Teachable Machine?

Teachable Machine es una herramienta gratuita de Google que permite entrenar modelos de aprendizaje automático sin escribir código. La persona que lo entrena reúne ejemplos (en este proyecto, fotografías), los organiza en grupos llamados clases y la herramienta ajusta un modelo capaz de distinguirlas.

El modelo resultante puede exportarse en formato TensorFlow.js. Esto permite ejecutarlo dentro de una página web, en el propio dispositivo de quien la usa, sin necesidad de enviar las imágenes a un servidor.

La problemática

Para una persona, reconocer a alguien en una fotografía es una tarea inmediata. Para un sistema informático, en cambio, implica aprender a partir de ejemplos. Este proyecto plantea una situación concreta: dada una imagen, determinar si corresponde a Kimberly, a una persona distinta o a un contenido diferente, e indicar qué tan segura es esa respuesta.

El proyecto también busca que quienes lo prueben comprendan una idea importante: un modelo de inteligencia artificial no «sabe» quién aparece en una imagen. Solo compara patrones que aprendió durante su entrenamiento, por lo que puede equivocarse. Por esa razón, la aplicación presenta siempre el porcentaje de confianza y nunca una respuesta absoluta.

La pregunta que guía el desarrollo es la siguiente: ¿cómo llevar un modelo de clasificación de imágenes a una aplicación que cualquier persona pueda abrir desde su celular o su computadora, sin instalar programas complejos?

Justificación: ¿por qué una PWA?

Una Progressive Web App (PWA) es una página web con características de aplicación. Se eligió este formato por las siguientes razones.

Un solo código para todos los dispositivos

La misma aplicación funciona en celulares Android, tabletas y computadoras, desde cualquier navegador moderno.

Instalable

Puede agregarse a la pantalla de inicio y abrirse como una aplicación, sin pasar por una tienda de aplicaciones.

Uso sin conexión

Después de la primera visita con Internet, la interfaz, las bibliotecas y el modelo quedan guardados en el dispositivo mediante un service worker.

Las imágenes se quedan en el dispositivo

El análisis se realiza en el navegador. Esta aplicación no envía las fotografías a ningún servidor.

Fácil de publicar y actualizar

Al ser archivos estáticos, se aloja gratuitamente en GitHub Pages y las nuevas versiones se distribuyen al actualizar el repositorio.

Objetivo general

Desarrollar una aplicación web progresiva que utilice un modelo de Teachable Machine para clasificar imágenes y mostrar el resultado junto con el porcentaje de confianza de cada clase, aplicando conocimientos de programación web e inteligencia artificial.

¿Cómo reconoce imágenes la inteligencia artificial?

El proceso completo tiene cuatro etapas, desde el entrenamiento hasta el resultado que se muestra en pantalla.

  1. Entrenamiento

    Se reúnen fotografías de ejemplo para cada clase. Teachable Machine las utiliza para ajustar una red neuronal preentrenada (MobileNet) a esta tarea específica.

  2. Preparación de la imagen

    Cuando se prueba una imagen, la aplicación toma su parte central y la reduce a 224 × 224 píxeles, que es el tamaño que el modelo espera recibir.

  3. Predicción

    La red neuronal analiza la imagen y calcula, para cada clase, un valor entre 0 y 1 que indica qué tanto se parece a los ejemplos con los que aprendió.

  4. Resultado

    Los valores se presentan como porcentajes. La clase con el porcentaje más alto es la que el modelo considera más probable, pero no garantiza que sea correcta.

Alcances y limitaciones

  • El resultado es una estimación estadística. No constituye una identificación con certeza absoluta.
  • La calidad de las respuestas depende de las fotografías usadas en el entrenamiento: su cantidad, variedad, iluminación y ángulos.
  • Una imagen muy distinta de las que vio el modelo, por ejemplo con poca luz o con la cara cubierta, puede producir resultados poco confiables.
  • Esta aplicación tiene fines educativos. No debe utilizarse para controlar accesos, verificar identidades ni tomar decisiones sobre personas.
