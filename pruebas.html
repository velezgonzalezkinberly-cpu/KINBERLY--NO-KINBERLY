Solución y pruebas del modelo

Aquí se utiliza el modelo entrenado en Teachable Machine. Elige una imagen, ejecuta el análisis y revisa el porcentaje de confianza de cada clase.

Cómo se utiliza el modelo

La solución es una página web que carga el modelo exportado desde Teachable Machine, lo ejecuta con TensorFlow.js y muestra los resultados sin depender de un servidor de análisis. Los archivos del modelo están en la carpeta modelo/ del proyecto.

  1. Al abrir esta página, la aplicación carga el modelo y sus metadatos (los nombres de las clases) y espera a que esté listo.
  2. Tú eliges una imagen o tomas una fotografía. Se muestra una vista previa.
  3. Al pulsar «Analizar imagen», el modelo calcula la probabilidad de cada clase.
  4. La aplicación muestra todas las clases con su porcentaje de confianza.

    Guía para realizar las tres pruebas

    Para evaluar el modelo, prueba una imagen de cada tipo y comprueba que la aplicación muestre el resultado y el porcentaje de confianza de todas las clases.

    Prueba 1: imagen de Kimberly

    Selecciona una fotografía de Kimberly. Se espera que la clase Kimberly obtenga el porcentaje más alto.

    Prueba 2: imagen que no es de Kimberly

    Selecciona una imagen que no sea de Kimberly. Se espera que la clase No es Kimberly obtenga el porcentaje más alto.

    Prueba 3: fotografía de otra persona

    Selecciona una fotografía de otra persona. Se espera que la clase Otra persona obtenga el porcentaje más alto.

    La clase «Otra persona» aparece únicamente si el modelo exportado la incluye. El apartado «Estado del modelo» muestra qué clases tiene el modelo cargado actualmente. El archivo README.md explica cómo organizar las clases en Teachable Machine.
